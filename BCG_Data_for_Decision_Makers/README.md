# 📊 BCG – Data for Decision Makers Job Simulation

## 📌 Overview

This repository contains my completed work for the **BCG – Data for Decision Makers Job Simulation** on Forage. The simulation focused on analyzing marketing campaign data, identifying business insights, and presenting data-driven recommendations to support strategic decision-making.

**Platform:** Forage
**Company:** Boston Consulting Group (BCG)
**Completed:** June 2026

---

## 🎯 Objectives

* Analyze marketing campaign performance using Excel.
* Organize and summarize business data with Pivot Tables.
* Create visualizations to compare campaign outcomes.
* Present findings and recommendations through an executive presentation.

---

## 🛠️ Tools Used

* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Microsoft PowerPoint

---

## 📋 Tasks Completed

### Task 1 – Campaign Data Analysis

* Analyzed campaign performance data using Excel.
* Created Pivot Tables to summarize sales and campaign metrics.
* Built Pivot Charts to compare campaign performance visually.

### Task 2 – Executive Presentation

* Prepared a business presentation summarizing the analysis.
* Highlighted key findings and provided data-driven recommendations for decision-makers.
