This repository contains my completed work for the **Deloitte Data Analytics Job Simulation** on Forage. The simulation focused on analyzing business data, preparing visual dashboards, and deriving meaningful insights to support data-driven decision-making.

**Company:** Deloitte
**Completed:** June 2026
